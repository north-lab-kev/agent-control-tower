ACT — a control tower for your coding-agent sessions

Assets. icons/icon.svg is the full app-tile mark; icons/icon-small.svg is the 16–24px variant, and the source for a favicon export at 16/32/48. The shipped src/Act.App/wwwroot/favicon.png and src/Act.App/icon.ico are raster exports — regenerate them from these two files, never by redrawing.

Colours live in code. src/Act.App/wwwroot/app.css is authoritative for every UI token. Editing a hex in this sheet changes nothing the user sees.

The wordmark is not implemented anywhere. This sheet is its only definition — Space Grotesk 700, .16em tracking, amber A. For a portable logo file, outline the text in a vector editor so it stops depending on the font.
