# Contributing to ACT

**ACT is not accepting external contributions at this time.** The project is in
early, fast-moving development and the design is still settling; opening it up
to outside pull requests would slow both sides down.

You are welcome to read the code, build it, and open issues for bugs you find.
To build from source, see [docs/development.md](docs/development.md).

When contributions open, they will be accepted under a Contributor License
Agreement / Developer Certificate of Origin (protects future dual-licensing) —
exact mechanism TBD.
